● LIVE GET /api/health

📖 3 Routes disponibles

POST /api/text
Texte seulement — question → réponse texte
{"message":"Explique Pythagore"}
POST /api/vision
Texte + Image — image base64 ou URL → analyse
{"message":"Que vois-tu ?","image":"data:image/png;base64,..."}
POST /api/auto ⭐
Auto + Figure — détecte fais une figure et génère un SVG
Mots-clés: figure, triangle, schéma, dessine, cercle, ABC...
{"message":"Fais une figure de deux triangles semblables ABC et RST"}
→ Réponse contient text + svg + figureDetected:true
Clé API : utilise celle par défaut ou passe X-API-Key: ta_cle dans le header.
Modèles : deepseek-v4.1-flash-1017, minimax-m3.1-flash, claude-haiku-5-5 (recommandé pour SVG)

 -d '{"message":"Fais une figure de deux triangles semblables ABC et RST"}'
